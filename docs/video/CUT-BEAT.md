# Cut Beat

An original kinetic-type promo template. CSS/JS, offline, time-driven. Select **Cut Beat** in the code-shot picker. Edit `CONFIG` in Edit code for words, type size, paper/dark palette, optional moving tile wall, label, local video/image and source time. Local media paths are relative to the page, for example `../assets/phone.mp4` after importing phone.mp4.

It is a scene template, not an automatic reference-to-reel system. Every shot's copy, timing, source, crop and layout were selected by hand. The design uses large type, short cuts, red on cream and mint on dark. It does not reproduce a competitor's exact edit, footage, narration or motion curves. The tile wall is original graphic artwork, not a scrape of social posts or a working feed.

## Proof, November 20, 2026

An 18-second nine-shot original Skye promo was created in Video: New project, import, insert Cut Beat shots, Edit code, add an audio bed in the mixer, export. No direct film.html writes assembled the project. A real screenshot of that project in Skye's editor was imported for the product beat. The original music bed was synthesized locally with oscillators/noise, no voice or model call. Stock footage was downloaded and reframed to 720x1280 with local ffmpeg before import. Those preparation steps were outside the Video UI.

The first fast scripted run clicked End while the board was refreshing. It selected the fallback insertion index and subsequent code edits targeted the wrong card. Inspection caught the wrong order/default pages. End/Start are now disabled until the board is ready. Shots were then individually selected by ID/card number and corrected through the UI, waiting for each native operation. This was developer-assisted execution, not a successful one-prompt autonomous edit.

## Limits

Text/footage remain editable as code-shot pages. The regular native timeline and Undo still apply, but there are no graphical word-by-word controls in this template. Video inside a code page is sought explicitly by frame time and awaited; this is heavier than a native footage layer. No segmentation, subject tracking, text-behind-person occlusion, speech alignment, lip sync, generative footage or 3D scene reconstruction is demonstrated. The beat is basic synthesized audio, not a polished commercial soundtrack.

Final verification: native UI H.264/AAC export, 18.000s, 480x854, 30fps, 1,915,027 bytes, server job 50.54 seconds on this host. Inspected a frame from all nine shots, corrected text safe widths, and exported again. Four scene clock checks (two video, tile wall, product image) repeated 0.3/0.9/0.3 seconds: the repeated images matched exactly and the other time differed, with no page errors. All nine steady-state text layouts fit within the frame. Native ZIP extraction into a new folder and first two seconds rendered successfully with the stock source. The rest of the reopened project was not fully rerendered. The exported audio has a measured sample peak of -1.8dBFS; this is not a listening-quality assessment.
